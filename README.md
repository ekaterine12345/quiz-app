# Computer Architecture Quiz App

A lightweight, fully-typed interactive quiz application built with **TypeScript**, **HTML5**, and **CSS3**. 
---

## Features

- **Typed Architecture:** Modular TypeScript with defined interfaces (`Question`, `Answer`) for type-safe data flow.
- **Separation of Concerns:** Questions decoupled into a standalone module (`questions.ts`) for easy editing and scalability.
- **Dynamic Scoring & UI:** Real-time feedback on answer selection, disabled states upon choice, and final score reporting.
- **Responsive Design:** Clean, simple UI adaptable across desktop and mobile screens.
